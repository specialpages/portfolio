# SpecialPages Portfolio

A professional, responsive static portfolio website for SpecialPages. It uses plain HTML, CSS and JavaScript, so it does not require Lovable, a database, or a build step.

## Preview locally
Open `index.html` in a browser.

## Before publishing
1. Edit `config.js`.
2. Add your Fiverr profile URL, client email, and WhatsApp number.
3. Replace concept cards with actual demo links only when those demos are live.
4. Review the page on mobile and desktop.

The project cards are labelled as concept demos; they are not presented as completed client projects.

## Deploy with GitHub Pages
1. Create a new public GitHub repository named `specialpages`.
2. Upload `index.html`, `config.js`, and `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Your site should be available at `https://tauqeer0028.github.io/specialpages/` after GitHub Pages finishes deploying.

This folder is a standalone static site and is not connected to a GitHub repository until you upload it.
